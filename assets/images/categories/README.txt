CATEGORY IMAGES - drop your photos in this folder.

Name each file after the category id and use the .jpg extension:

  deals.jpg      (Deals & Combos)
  burgers.jpg    (Burgers)
  broast.jpg     (Crispy Broast)
  pizza.jpg      (Pizza)
  special.jpg    (Special Pizza)
  wraps.jpg      (Wraps & Shawarmas)
  rolls.jpg      (Rolls)
  fries.jpg      (Fries)
  appetizers.jpg (Appetizers)
  dips.jpg       (Dips)
  tea.jpg        (Tea & Coffee)

Best size: 800 x 600 px (4:3), under ~150 KB each.
The website picks them up automatically - no code change needed.
Until a file exists, the site shows an "Add Category Image Here" box.

Using PNG/WebP instead? Change  categoryImages.ext  in js/config.js,
or set  img:"assets/images/categories/yourfile.png"  on one category in js/menu.js.
